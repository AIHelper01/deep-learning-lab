# 深度学习实验项目导览

本项目围绕图像分类、目标检测和中文情感分析组织教学材料，核心载体为 Jupyter Notebook。适合用来理解模型原理、完成训练与预测实验，并逐步学习如何评估模型。

本文只梳理现有内容并提出整理建议，不改变代码、Notebook、依赖或目录结构。检查依据为当前本地文件；尚未安装环境或执行训练，运行状态不能依据历史输出判定。

## 2. 按任务理解三个模块

| 模块 | 要解决的问题 | 核心知识 | 实验产物 |
|---|---|---|---|
| 图像分类 | 一张图片属于哪个类别？ | 卷积网络、数据预处理、训练循环、迁移学习 | 分类模型、训练曲线、预测结果；部分实验有混淆矩阵 |
| 目标检测 | 图片中有什么，分别在哪里？ | 边界框、IoU、NMS、YOLO、数据标注格式 | 在外部检测工程中训练得到的权重与检测结果 |
| 情感分析 | 一段中文评论表达什么情感？ | 分词、词向量、序列补齐、双向 LSTM | 词表、文本分类模型与预测结果 |

这些产物描述实验目标，并不表示当前目录已经包含训练结果或模型权重。

## 3. 建议的学习顺序

### 第一阶段：用 MNIST 掌握完整实验流程

主入口：[LeNet-MNIST 规范版](2.1深度学习-ImageClassification/LeNet-5/01_LeNet-MNIST手写数字识别分类器-规范版.ipynb)。

按正文顺序完成：数据观察 → 张量维度检查 → 模型定义 → 训练与评估 → 保存与加载 → 单张图片预测。先理解正文中的分步流程，再阅读最后的完整训练系统附录。

本阶段的学习完成标准：能够解释输入与输出形状、训练和评估的区别，并能保存模型后重新加载进行预测。

### 第二阶段：从数字识别扩展到彩色图像

1. [LeNet-CIFAR10](2.1深度学习-ImageClassification/LeNet-5/02_LeNet-CIFAR10分类器.ipynb)：关注输入通道、预处理和任务难度的变化。
2. [ResNet-CIFAR-10](2.1深度学习-ImageClassification/ResNet/01_ResNet-CIFAR-10.ipynb)：理解预训练网络的使用，以及输出分类层如何适配任务。
3. [LeNet-MNIST 进阶版](2.1深度学习-ImageClassification/LeNet-5/01_LeNet-MNIST手写数字识别分类器-进阶版.ipynb)：在准备好 LEDNUM 后，再学习自定义数据索引与 Dataset。

比较模型时，需要记录数据划分、预处理、训练轮数和预训练设置，避免仅凭不同实验的最终准确率得出结论。

### 第三阶段：按兴趣进入两个分支

完成基本训练流程后，目标检测与情感分析可以分别学习。情感分析不必以跑通目标检测为前提。

**视觉分支：** [理解卷积](2.2深度学习-ObjectDetection/理解卷积.md) → [YOLO理论](2.2深度学习-ObjectDetection/YOLO理论) → [YOLO实践](2.2深度学习-ObjectDetection/YOLO实践) → 剪刀石头布检测教程。

[CV 基础梳理版](2.2深度学习-ObjectDetection/CV基础_PPT内容梳理版.md) 适合作为总览或复习材料，其中 ViT、Diffusion 等内容可作为拓展阅读。检测 Notebook 以讲解为主，包含 43 个 Markdown 单元和 3 个代码单元，需要配合外部 PaddleYOLO/PaddleDetection 工程使用。

**文本分支：** 先选一套框架贯穿学习。

| 路线 | 顺序 | 重点 |
|---|---|---|
| PyTorch | 11 自然语言处理综述 → 12 词向量 → 13 LSTM 情感分类 | 可延续图像分类模块的框架知识；运行前需要补齐依赖 |
| Paddle | 01 自然语言处理综述 → 02 词向量 → 03 LSTM 情感分类 | PaddleNLP 词向量、数据处理与 LSTM 实践；需核对版本组合 |

先掌握一条路线，再对照另一条路线的 Dataset、Embedding、LSTM 和训练接口。BERT/ERNIE 示例与手动训练 LSTM 应作为不同实验理解，分别核对模型来源、任务训练情况和评估结果。
