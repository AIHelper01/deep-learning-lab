# Learning path

English (default) · [中文](learning-path.zh-CN.md)

1. [LeNet on MNIST](../english/01-image-classification/notebooks/01-lenet-mnist.ipynb): inspect data, understand tensor shapes, train, evaluate, save and reload a model.
2. [LeNet on CIFAR-10](../english/01-image-classification/notebooks/02-lenet-cifar10.ipynb): move to color images.
3. [ResNet18 on CIFAR-10](../english/01-image-classification/notebooks/03-resnet-cifar10.ipynb): transfer learning and validation checkpoint selection.
4. Choose [object detection](../english/02-object-detection/README.md) or [sentiment analysis](../english/03-sentiment-analysis/README.md). Neither branch requires the other.

Custom image folders, the compact MNIST archive, and pretrained DistilBERT are optional. For NLP, finish one framework route before comparing PyTorch with Paddle.

An experiment is complete when you can explain inputs and outputs, reproduce preprocessing and training, report evaluation metrics, inspect failures, and verify reloaded predictions. Align splits, preprocessing, epochs, and pretrained weights before comparing models.

For Chinese explanations and Chinese sentiment data, use the [Chinese course](../README.zh-CN.md). Language editions are separate experiments, not interchangeable datasets.
