# Chinese YOLO26 outputs

Current Chinese YOLO26n checkpoints, training curves, predictions, and metrics are written here. The official v1 dataset and pretrained weights are shared with the English detection module. English outputs remain in `english/02-object-detection/outputs/`.

The vehicle-counting lesson writes `vehicle-counting-metrics.json`, `vehicle-flow-report.json`, its `runs/` directories, and `traffic-demo.mp4` plus `traffic-demo.ground-truth.json` (the synthetic clip built by `english/scripts/build_traffic_demo_video.py`) here as well.

The figures embedded in that notebook are also exported for the lesson pages under [`../assets/`](../assets/) as `vehicle-counting-1..7.png`; the walkthrough with every saved output is [the vehicle-counting run report](../lessons/05-vehicle-counting-run-report.md).

Generated files are excluded from Git. See [the Chinese course](../README.md) and [execution reports](../../english/reports/README.md).
