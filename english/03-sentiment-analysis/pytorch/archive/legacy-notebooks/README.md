# Legacy Chinese notebooks (read-only archive)

These are the early Chinese notebooks for this module. They are archived because:

- their cell structure does not line up with the rebuilt English masters in `english/03-sentiment-analysis/pytorch/notebooks/`;
- their dependencies do not match the locked course environment, so they cannot be reproduced here;
- some cells contain syntax errors or stale failure outputs that no longer match the code.

The current Chinese course lives in `03-sentiment-analysis/pytorch/notebooks/` and is mirrored from these English
masters by `scripts/build_chinese_course.py` at the repository root: Chinese narration,
Chinese console output, Chinese plot labels, and a one-to-one match with the English lessons.

Archived files stay in the repository for reference only. They are not executed or validated.
Use `git log --follow <path>` to inspect their history.
